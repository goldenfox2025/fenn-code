# Ancora 0.1.1

A composer footer like Claude's, chats grouped by folder, sub-conversations, faster first replies, usage straight from the agent, glass in light or dark, and fixes for Qoder and Codex setups that 0.1.0 couldn't start.

> **Unofficial.** Ancora is an independent open-source project, not affiliated with, endorsed by or sponsored by Anthropic, OpenAI, xAI or Qoder. "Claude" is a trademark of Anthropic.

**Download:** `Ancora-Setup-0.1.1.exe` (installer) or `Ancora-0.1.1-win.zip` (unzip anywhere and run `Ancora.exe`). The build is not code-signed, so if SmartScreen asks, choose **More info → Run anyway**. Releases are Windows only: macOS and Linux build from source with `build.sh` (see the README).

## What's new

- **Composer like Claude's.** Under the message box: the agent, the model, the thinking level and a context ring, the same on the home page, in chats, projects and threads. The agent menu lists only installed agents (more go under *More agents*), the model menu shows the agent's top models (the rest under *More models*), and the thinking level opens a 速度更快 … 更智能 slider with the recommended level marked.
- **Chats grouped by folder.** Below your pinned projects, chats are listed under the folder they work in, with a 「+」 to start another chat there; chats without a folder have a group of their own. The Chats page is grouped the same way. Chats never move into projects: a project is its own chat plus threads. A new chat whose first turn clearly worked in a folder you've used is quietly attached to it.
- **A folder only when it's needed.** A new chat has no project picker and no folder until you choose one. When the agent makes files in a chat without a folder, the chat gets its own folder named after it in Documents/Ancora (changeable in Settings → General), with a 「Saved in …」 line and a link to open it. Chats that only talk never get one.
- **Replies read like Claude's.** Thinking, tool calls and anything the agent says between them fold into one quiet steps line, then the answer. While it works, three dots and the time so far sit at the bottom of the reply. Tooltips are small rounded bubbles instead of the system's boxy ones.
- **Sub-conversations.** When a chat reaches a piece of side work, the agent can hand it to a new conversation in the same folder. It appears nested under the chat, opens with the task it was given, and from then on you talk to it directly.
- **Never picks an agent you don't have.** New chats, projects and scheduled tasks use Codex when it is installed, otherwise the first agent that is installed and signed in. A project or scheduled task whose agent is signed out keeps it, runs on another agent for now, and says so in the reply.
- **Faster first reply.** Opening a conversation connects to its agent in the background, so sending only sends. While it still connects the reply says *Connecting to …* rather than *Thinking…*, and an agent that doesn't connect within a minute shows an error you can retry.
- **Usage straight from the agent.** Numbers come from what the agent reports over ACP, or else from its own session log (Codex, Claude Code, Grok), never from an estimate. The headline is new input plus output, with cache reads and writes on their own rows. The ring shows the last call against the context window; when the agent doesn't say how big the window is, a bundled table of model limits fills it in, and without one it shows tokens used. An agent that reports nothing says so.
- **Diagnostics.** Settings → About can log every message to and from agents (off by default), to look into usage or connection problems.
- **Glass in light or dark.** Settings → Appearance now has Color (light, dark, follow the system) and a separate Glass switch. The old Glass theme carries over as dark with glass on.
- **Threads are milestones.** In a project, a follow-up goes to the thread that already covers it (reopening a resolved one), threads with the same title aren't opened twice, and resolved threads aren't copied into a second progress list.
- **Model choice before the first message.** Opening the model menu loads the agent's models and thinking levels without sending anything. Each agent remembers its own model and thinking level.
- **Switch agents in an idle chat.** The new agent receives the conversation so far.
- **Qoder credits.** For Qoder, the usage button shows your account's plan credits, read without sending a prompt.
- **Last reply timing.** The usage menu shows how soon the last reply started and the average time per token, as the app observed it.

## Fixes

- Qoder installed through npm on Windows now starts through its own Node entry, so stopping a check really stops it. You can also set the Qoder CLI path and the Node to run it with.
- Codex can use a CLI path and an ACP adapter path, for a `codex` that is an alias or lives inside another app.
- Settings checks whether each agent is actually installed before offering it. Project and scheduled-task forms list only agents that can answer.
- Editing `backends.json` takes effect without clicking Reload.
- The install and upgrade confirmation lays out long commands correctly.
- A permission mode picked for one new chat no longer carries over to the next one.
- Local file errors (permissions, read-only folders) are no longer reported as sign-in problems.
- The window fits smaller screens, and menus shrink and scroll instead of covering their button.
- Releases no longer include the demo agent.
- With Qoder signed out, the model menu says so and links to sign-in instead of failing.
- Switching agents in the middle of a chat now shows the new agent's own model, mode and thinking levels, and never sends it the previous agent's model.
- A button's tooltip no longer covers the menu it opened.

# Ancora 0.1.1

输入框底栏改成和 Claude 一样；对话按文件夹分组；新增子对话；第一次回复更快；用量直接来自 agent；玻璃效果可以配浅色或深色；还修复了 0.1.0 里一些 Qoder 和 Codex 装法启动不了的问题。

> **非官方项目。** Ancora 是独立的开源项目，与 Anthropic、OpenAI、xAI、Qoder 均无关联，也没有得到它们的认可或赞助。「Claude」是 Anthropic 的商标。

**下载：** 安装包 `Ancora-Setup-0.1.1.exe`，或免安装的 `Ancora-0.1.1-win.zip`（解压到任意位置，运行 `Ancora.exe`）。程序没有代码签名，如果 SmartScreen 拦截，点「更多信息 → 仍要运行」。发布页只提供 Windows 版本，macOS 和 Linux 请用 `build.sh` 从源码编译（见 README）。

## 新功能

- **输入框和 Claude 一样。** 输入框下方依次是 agent、模型、努力程度和上下文圆环，首页、对话、项目和讨论串里都一样。agent 菜单只列装好的 agent（多的放进「更多后端」），模型菜单列出常用的几个（其余在「更多模型」里），努力程度点开是「速度更快 … 更智能」的滑块，标出推荐档位。
- **对话按文件夹分组。** 置顶的项目下面，对话按工作文件夹分组，每组旁边的「+」可以在这个文件夹里再开一个对话；没有文件夹的对话单独一组。「对话」页面也这样分组。对话不会再被放进项目：项目就是项目自己的对话加讨论串。新对话第一轮明确在某个用过的文件夹里干活时，会悄悄归到那个文件夹。
- **需要时才有文件夹。** 新对话没有项目选择，也默认不选文件夹。没选文件夹的对话里 agent 一做出文件，就在「文档/Ancora」里按对话标题建一个文件夹，把文件放进去（位置可在 设置 → 通用 里改），回复下方显示「已放在 …」和打开链接。只聊天的对话不会建。
- **回复的样子和 Claude 一样。** 思考、工具调用以及 agent 在中间说的话，都收进一行安静的步骤，下面才是回答。工作时，回复底部显示三个点和已用时间。提示气泡改成小圆角气泡，不再是系统的方框。
- **子对话。** 对话推进到一块旁支工作时，agent 可以把它交给同一个文件夹里的新对话。子对话挂在原对话下面，开头写着交给它的任务，之后您直接在里面和它说。
- **不会默认选没装的 agent。** 新对话、项目和定时任务装了 Codex 就用 Codex，否则用第一个装好并已登录的 agent。项目或定时任务选的 agent 没登录时，设置不变，本次先换一个 agent 运行，并在回复里说明。
- **第一次回复更快。** 打开对话时就在后台连上 agent，按回车只需要发送。还在连接时显示「正在连接 …」而不是「正在思考…」；一分钟内连不上会报错，可以重试。
- **用量直接来自 agent。** 数字来自 agent 通过 ACP 报告的用量，没有就读它自己的会话日志（Codex、Claude Code、Grok），从不估算。总数是新输入加输出，缓存读取和写入单独列出。圆环显示最近一次调用占上下文窗口的多少；agent 没说窗口多大时查内置的模型上限表，查不到就只显示已用多少。agent 什么都不报时会直接说明。
- **诊断。** 设置 → 关于 里可以记录与 agent 往来的每条消息（默认关闭），用来排查用量或连接问题。
- **玻璃效果配浅色或深色。** 设置 → 外观 里分成「颜色」（浅色、深色、跟随系统）和单独的「玻璃效果」开关。原来的太空玻璃主题会变成深色加玻璃效果。
- **讨论串就是里程碑。** 项目里的追问会发到已有的讨论串（已解决的会重新打开），同名讨论串不会重复开，解决的讨论串也不会再抄一份到进度表。
- **第一条消息之前就能选模型。** 打开模型菜单时会读取 agent 提供的模型和思考强度，不会发送任何内容。每个 agent 各自记住自己的模型和思考强度。
- **空闲的对话可以换 agent。** 新的 agent 会拿到之前的对话内容。
- **Qoder 账户 Credits。** 用 Qoder 时，用量按钮显示账户套餐的 Credits，查询时不发送任何提示。
- **最近一次回复的速度。** 用量菜单里显示最近一次回复多久开始，以及平均每个 token 用了多久（应用这边观测到的数字）。

## 修复

- 在 Windows 上用 npm 装的 Qoder，现在通过它自己的 Node 入口启动，停止检查时能真正停下来。也可以自己填 Qoder CLI 路径和运行它的 Node。
- Codex 可以填 CLI 路径和 ACP 适配器路径，适合 `codex` 是别名或装在别的应用里的情况。
- 设置会先确认 agent 真的装好了再提供；项目和定时任务的表单只列出能用的 agent。
- 修改 `backends.json` 后自动生效，不用再点「重新加载」。
- 安装和升级的确认框能正确显示很长的命令。
- 在一个新对话里选的权限模式，不会再带到下一个新对话。
- 本地文件读写出错（权限、只读文件夹）时，不会再被说成是登录问题。
- 窗口能适应较小的屏幕；菜单放不下时会缩短并滚动，不再挡住按钮。
- 发布版本里不再包含演示 agent。
- Qoder 没登录时，模型菜单会直接说明并给出登录入口，不再报错。
