# Ancora 0.1.0 (preview)

The first public release of Ancora, a desktop workspace for command-line AI agents. This is a preview: the Windows build is tested on Windows 11, and it is not code-signed yet.

> **Unofficial.** Ancora is an independent open-source project, not affiliated with, endorsed by or sponsored by Anthropic, OpenAI, xAI or Qoder. "Claude" is a trademark of Anthropic.

**Download:** `Ancora-0.1.0-win.zip` below. Unzip it anywhere and run `Ancora.exe`. If SmartScreen asks, choose **More info → Run anyway**. macOS and Linux can build from source with `build.sh` (see the README); those builds have not been verified on hardware yet.

## What's in it

- **Chats** with streaming replies, tool calls, plans, permission prompts, attachments, editing and regenerating with version history, and per-conversation model, mode and thinking level.
- **Projects**: a coordinator agent in the project chat starts **threads** for focused work. Threads keep a live checklist, report their current obstacle and ask for decisions with cards. An overview and a progress board of milestones show where everything stands. Project memory, files and progress outlast any single agent session.
- **Computer use** (off by default): agents whose model reads images can work in other apps. They must ask for each app, and you grant full control, click only or view only.
- **Agents**: Codex, Claude Code, Grok and Qoder built in, plus any ACP agent through `backends.json`. Codex is the recommended default and is tested end to end. Claude Code is supported through `claude-agent-acp` with the connection verified (start-up and model list); a full chat has not been tested yet. Ancora never installs an agent on its own: install and upgrade show the exact command and wait for your confirmation.
- **Outputs**: files and links agents hand over appear as cards and in each project's Outputs library.
- **Scheduled tasks**: once, interval, daily, weekly or cron, posting to a project, a conversation or a new chat. Agents can create them too.
- **Also**: MCP connectors, working folders, full-text search, automatic filing of loose chats into projects, token and cost usage as reported by the backend, desktop notifications, light, dark and glass themes, and an English or Simplified Chinese interface.

## Before you start

Install and sign in to at least one agent. The README lists the commands for each, and Settings → Agent backends shows what is installed and signed in.

## Known limitations

- Not code-signed, so Windows SmartScreen warns on first run.
- macOS and Linux builds are untested on real hardware. Computer use on macOS needs the Accessibility and Screen Recording permissions; on Linux it needs X11 and `xdotool` (Wayland isn't supported).
- Computer use needs an agent whose model accepts images.

Feedback and bug reports are welcome in Issues, in English or Chinese.

# Ancora 0.1.0（预览版）

Ancora 的第一个公开版本，一个为命令行 AI agent 准备的桌面工作台。这是预览版：Windows 版本已在 Windows 11 上实测，暂时没有代码签名。

> **非官方项目。** Ancora 是独立的开源项目，与 Anthropic、OpenAI、xAI、Qoder 均无关联，也没有得到它们的认可或赞助。「Claude」是 Anthropic 的商标。

**下载：** 下方的 `Ancora-0.1.0-win.zip`，解压到任意位置，运行 `Ancora.exe`。如果 SmartScreen 拦截，点「更多信息 → 仍要运行」。macOS 和 Linux 可以用 `build.sh` 从源码编译（见 README），这两个平台尚未在真机上验证。

## 包含什么

- **对话**：流式回复、工具调用、计划、权限确认、附件、编辑和重新生成（保留历史版本），每个对话可以单独选模型、模式和思考强度。
- **项目**：项目主对话里的协调 agent 会为要花功夫的工作开**讨论串**。讨论串有实时进度清单，会写明当前难点，需要拍板时发选择卡片。概览页和里程碑进度表让您一眼看清进展。项目记忆、项目文件和进度不依赖任何一个 agent 会话。
- **电脑操控**（默认关闭）：模型能看图的 agent 可以在其他程序里干活。它必须先申请每个程序，由您选择完全控制、仅点击或仅查看。
- **Agent**：内置 Codex、Claude Code、Grok 和 Qoder，其他 ACP agent 可通过 `backends.json` 接入。Codex 是推荐的默认后端，已完整实测；Claude Code 通过 `claude-agent-acp` 接入，已验证连接（启动和模型列表），完整对话尚未实测。Ancora 从不自行安装 agent：安装和升级都会先显示确切命令，等您确认后才执行。
- **成果**：agent 交付的文件和链接显示成卡片，并汇总在每个项目的「成果」页。
- **定时任务**：一次、间隔、每天、每周或 cron，结果发到项目、某个对话或新对话。agent 也可以自己建。
- **另外**：MCP 连接器、工作文件夹、全文搜索、零散对话自动归入项目、按后端上报显示的 token 用量和费用、桌面通知、浅色/深色/太空玻璃主题，以及中英文界面。

## 开始之前

请至少安装并登录一个 agent。README 里列出了每个 agent 的命令，设置 → Agent 后端 里能看到哪些已安装、已登录。

## 已知限制

- 没有代码签名，第一次运行时 Windows SmartScreen 会提示。
- macOS 和 Linux 版本尚未在真机上测试。macOS 上的电脑操控需要「辅助功能」和「录屏与系统录音」权限；Linux 上需要 X11 和 `xdotool`（不支持 Wayland）。
- 电脑操控需要模型能接收图片的 agent。
